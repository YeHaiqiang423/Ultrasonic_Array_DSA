### 一、 物理层 IO 接口 (FPGA 外部引脚)

这些是直接与外部硬件（Mizar Z7 底板、超声波驱动板、ADC 采集板）发生物理电气连接的引脚。

#### 1. 系统核心控制
| 信号名称 | 方向 | 硬件引脚参考 | 电平 / 频率关系 | 作用描述 |
| :--- | :--- | :--- | :--- | :--- |
| **`sys_clk_50m`** | Input | [cite_start]**H16** (Bank 13) [cite: 659] | **50MHz** | Mizar Z7 开发板板载的 PL 侧有源晶振输入，作为整个系统的基准时钟。 |
| **`sys_rst_n`** | Input | [cite_start]**B18** [cite: 715] | **低电平有效** (0=复位) | 开发板上的硬件复位按键输入。 |

#### 2. ADC 采集接口 (对接 XCS7478)
| 信号名称 | 方向 | 电平 / 频率关系 | 作用描述 |
| :--- | :--- | :--- | :--- |
| **`adc_cs_n`** | Output | **低电平有效** (1us 周期) | 片选信号。拉低时唤醒 ADC 开始转换并输出数据；拉高时 ADC 待机。采集率为 **1 MSPS**。 |
| **`adc_sclk`** | Output | **25MHz** | SPI 串行同步时钟。由 100MHz 四分频得到，在下降沿触发 ADC 输出，上升沿 FPGA 采样。 |
| **`adc_sdata`** | Input | 高低电平表征 0/1 | ADC 吐出的串行比特流。包含前导码和 8-bit 量化后的音频电压数据。 |

#### 3. 超声阵列驱动接口 (对接 74AHCT595 & UCC27624)
| 信号名称 | 方向 | 电平 / 频率关系 | 作用描述 |
| :--- | :--- | :--- | :--- |
| **`stcp`** | Output | **40kHz** (周期 25us) | **锁存时钟**。产生上升沿时，将移位寄存器中的数据瞬间推送到输出端，决定了超声波的**载波频率**。 |
| **`shcp`** | Output | **高速突发脉冲** | **移位时钟**。产生上升沿时，将 `ds` 上的数据吞入 595 内部。每 25us 内爆发 8 个脉冲。 |
| **`ds1` ~ `ds4`** | Output | 高低电平表征 PWM | 4 根并行数据线，每根串行发送 8 bit。高电平(1)驱动换能器发声，低电平(0)关闭。其高电平的持续时间（占空比）代表了当前音频的振幅。 |
| **`ucc_en`** | Output | **高电平有效** | 功放驱动阵列的全局使能端。拉高允许发波，拉低强制静音（硬件级保护）。 |

### 二、 核心内部寄存器 (RTL 逻辑层)

这些是你代码中定义的关键变量，决定了时序的流转和音频调制的精度。

#### 1. 时钟与定时基准
| 寄存器 / 信号 | 位宽 | 触发条件 / 频率 | 核心作用 |
| :--- | :--- | :--- | :--- |
| **`clk_100m`** | 1 bit | **100MHz** | 由 PLL 倍频产生的主系统时钟，驱动所有状态机。 |
| **`locked`** | 1 bit | 异步变高 | PLL 锁定标志位。只有它拉高后，内部逻辑才会解除复位开始工作。 |
| **`timer_1us`** | 7 bit | `0 ~ 99` 循环 | ADC 的 1us 定时器。每数到 99 (100个时钟周期) 触发一次 `adc_cs_n` 拉低。 |
| **`tick_cnt`** | 5 bit | `0 ~ 17` 循环 | 595 驱动的底层节拍器。每数到 17（18个周期），产生一次 `tick_en` 脉冲。 |

#### 2. 波束成型与 PWM 发生 (pwm_array_core)
| 寄存器 / 参数 | 位宽 | 数值范围 / 关系 | 核心作用 |
| :--- | :--- | :--- | :--- |
| **`MAX_HW_STEPS`**| 常量 | **139** | 40kHz 周期被切分的刻度总数。反推逻辑：$100MHz / (18 \times 139) \approx 40kHz$。 |
| **`pwm_cnt`** | 8 bit | `0 ~ 138` 循环 | 载波的时间刻度。每逢 `tick_en` 累加一次，当它清零时，意味着一个新的 40kHz 周期开始。 |
| **`hw_duty`** | 7 bit | `0 ~ 69` 动态变化 | **音频调制的核心**。由 12-bit 音频数据除以 59 得到。数值越大，代表当前输出的正弦波占空比越宽（振幅越强）。 |
| **`phase_offset`**| 8 bit | 默认 `0` | 每路换能器的相位偏移量。未来可以通过改变这里的值，实现超声波束的偏转（相控阵）。 |
| **`local_cnt`** | 8 bit | 动态计算 | 单路等效时间 = `(pwm_cnt + phase_offset) % 139`。当 `local_cnt < hw_duty` 时，该路输出高电平。 |

#### 3. 数据流缓冲
| 寄存器 | 位宽 | 数据流向 | 核心作用 |
| :--- | :--- | :--- | :--- |
| **`sum_pool`** | 13 bit | ADC -> Filter | 过采样累加器。将 25 次 8-bit 的 ADC 采样值累加起来，防止溢出。 |
| **`audio_out`** | 12 bit | Filter -> PWM Core | 经过过采样提升分辨率后的音频数据（0~4095）。 |
| **`error_acc`** | 6 bit | 内部运算 | 占空比计算时的“余数累加器”。保留了除法丢失的小数精度，防止音频高频细节丢失。 |
| **`shift_reg`** | 32 bit | PWM Core -> 595 | 准备发送给底层 74HC595 的 32 路开关状态大礼包，每 25us 刷新一次。 |
